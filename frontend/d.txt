docker run [OPTIONS] IMAGE [COMMAND] [ARG...]

OPTIONS :

docker run -p 3000:3000 frontend-app

What exactly is 3000:3000 : It is the value (argument) of the -p option.

-p HOST_PORT:CONTAINER_PORT

Option WITHOUT argument/value : -d , -it , --rm
Option WITH argument/value : --name ==> docker run -p 3000:3000 --name fc  frontend-app
--name fc → give a custom name to the container
-------------------------------------------------------------------------

Short options (-d) → convenient, quick
Long options (--rm) → descriptive, readable
Both exist to balance speed vs clarity
